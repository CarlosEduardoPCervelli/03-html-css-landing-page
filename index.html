Sobre o projeto

O TaskFlow é um projeto pessoal criado para praticar organização de tarefas no dia a dia. A ideia surgiu da dificuldade de usar apps complexos só para anotar coisas simples — então a proposta aqui é o oposto: uma lista rápida, sem cadastro, sem anúncio e sem telas desnecessárias.

É um projeto em desenvolvimento, feito como prática de HTML, CSS e JavaScript, e vai ganhando novas funcionalidades com o tempo.
